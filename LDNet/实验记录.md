# LDNet 实验记录

## 架构

```
输入 5ch × 512×512
      │
      ▼
┌─────────────────────────┐
│  SwinV2_LCSRB Backbone  │  ← 共享 (small/base, 预训练)
│  输出 4 个尺度特征图       │
└─────────────────────────┘
      │
   ┌──────────────────┐
   │   feat.copy()     │
   └──────────────────┘
      │                    │
      ▼                    ▼
┌──────────────┐     ┌──────────────┐
│ 分支1 Binary  │     │ 分支2 4-Class │
│              │     │              │
│ PPM          │     │ PPM          │
│ FPNPAN       │     │ FPNPAN       │
│ conv_fusion  │     │ conv_fusion  │ ← 多 1ch gate 输入
│ head → 1ch   │     │ head → 4ch   │
│              │     │       ▲      │
│ sigmoid ─────┼─────┘  Gate  │
└──────┬───────┘     └──────┬───────┘
       │                    │
       ▼                    ▼
 pred_binary            pred_class
 (B,1,H,W)              (B,4,H,W)
 [0,1]                  [WR,Rille,Fault,Graben]

推理合并: final = argmax(b2)+1 × (b1 > 0.5)
```

## Loss

| 分支 | Loss | 计算范围 |
|------|------|----------|
| 分支1 | BCE + Dice | 全部像素, GT 二值化 (0→0, 1-4→1) |
| 分支2 | CE | 仅 GT>0 像素, 类别 1-4 → 0-3 |

## 实验记录

### R1 — 双分支基线 (2026-07-31)

**配置**: small + BCE+Dice(B1) + CE(B2) + tile_sample(exp=0.3) + CopyPaste + v5数据
**对比基线**: STDL-Net R50 (单分支 mIoU=0.502)

| 指标 | R50 (单分支) | R1 (双分支) | Δ |
|------|-------------|------------|---|
| mIoU | 0.502 | - | - |
| WR IoU | 0.439 | - | - |
| Rille IoU | 0.430 | - | - |
| Fault IoU | 0.297 | - | - |
| Graben IoU | 0.358 | - | - |
| Graben Recall | 43.1% | - | - |

## 优化路线

```
R1: 双分支基线 (small, 与 R50 配置对齐)
  ↓
R2: Branch2 换轻量 CNN Decoder (消融: decoder 是否过重?)
  ↓
R3: 调整 loss 权重 (bce/dice/ce 比例)
  ↓
R4: 换 base 模型
```

## 关键参数速查

| 参数 | R1 默认值 | 含义 |
|------|----------|------|
| bce_weight | 1.0 | 分支1 BCE 权重 |
| dice_weight | 1.0 | 分支1 Dice 权重 |
| ce_weight | 1.0 | 分支2 CE 权重 |
| class_weights_4 | [1, 1.3, 1.8, 2.5] | 分支2 四分类权重 |
