# 消融实验总结

以 R17 Baseline (mIoU=0.5368) 为基准，逐一验证各模块的贡献。

---

## 模块消融

| Run | 模块 | mIoU | Δ mIoU | 结论 |
|------|------|------|--------|------|
| R17 | Baseline | 0.5368 | — | 基准 |
| R19 | + Strip Pooling | 0.5153 | -0.0215 | 负收益 |
| R20 | + Coordinate Attention | 0.4692 | -0.0676 | 严重负收益 |
| R21 | + Boundary Supervision | 0.5205 | -0.0163 | 轻微负收益 |
| R22 | + DEM-Guided Fusion | 0.4652 | -0.0716 | 严重负收益，大量误检 |
| R23 | + Multi-modal Gating | 0.4733 | -0.0635 | 严重负收益 |

---

## 关键发现

1. **所有结构模块均未超过 Baseline**，说明 Baseline 架构已经较优
2. **DEM-Guided Fusion 问题最严重**，引入后产生大量误检，Precision 显著下降
3. **Coordinate Attention 最不适用**，mIoU 下降 6.76%
4. **数据集优化 (v6) 对 Graben 有效**，但整体 mIoU 略降，需进一步调优
5. **类别权重强化适得其反**，过度加权少数类反而损害整体性能
