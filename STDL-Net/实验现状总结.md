### 有效的技术手段
1. **加权tile采样** (`use_tile_sampling: true, tile_sample_exp: 0.3`) — 最大提升
2. **Base模型** (`model_size: base`) — 比small提升+0.019
3. **多尺度增强** (`use_scale_aug: true, scale_range: [0.9, 1.1]`) — 抗过拟合
4. **Tversky Loss** (`α=0.68, β=0.32`) — 精确控制P/R平衡
5. **class_weights** — 微调有效但空间有限

## Scene-Level 划分方案 (v8)

### 问题诊断
- 旧方案(v6): 从 train 随机抽取 10% tile 做 val → **数据泄漏**
- 同一 Scene 的相邻 tile 共享光照/纹理/地质特征 → val 虚高 0.68 vs test 0.40
- v7 的教训: train 完全不含 Mare → 域迁移太大, 模型不会 Mare 样式
- **根因: 需要 Scene 隔离, 但 train 必须保留一部分 Mare**

### 当前方案: Mare Serenitatis 内按行切分 (split_row=6447)

```
Mare Serenitatis 网格:
┌──────────────────────┐
│  rows < 6447         │ → Val (372 tiles, WR 丰富)
│  (低行号, WR 密集)    │
├──────────────────────┤
│  rows ≥ 6447         │ → Train (111 tiles, Graben 丰富)
│  (高行号, Graben 密集) │
└──────────────────────┘
```

- **Train**: Mare 高行号 111 + 其他 22 个 Scene 1397 = **1508 tiles (74.2%)**
- **Val**: Mare 低行号 372 = **372 tiles (25.8%)**
- **Test**: Mare 独立区域 331 tiles，完全不参与训练
- Catena-* Scene(19 个, 364 tiles) 全为纯背景
- 划分脚本:
  1. `scripts/split_by_scene.py` —— 穷举 Scene 组合&统计全局分布
  2. `scripts/resplit_mare_graben.py` —— 对 Mare 按行统计后执行新切分
- Split 文件生成至 `datasetv8/pretrain/*.txt`，需同步到 `dataset_analysis/` 供本地训练；Kaggle 数据集亦需携带同名文件

### Graben 域迁移问题 (关键发现)

Train (新切分) 的 Graben 像素来自：

| Scene | 含 Graben tile | Graben 像素 | 占全部 Graben 像素 | 备注 |
|-------|----------------|-------------|---------------------|------|
| Rima Ariadaeus | 172 | 5,612,889 | **73.1%** | 宽而深的陆地裂谷 |
| Mare Serenitatis 高行 | 62 | 1,866,635 | **24.3%** | **细长的 Mare 型地堑** |
| Aristarchus | 34 | 164,434 | 2.1% | 次要贡献 |
| Marius Hills | 30 | 39,556 | 0.5% | 几乎无影响 |

Val/Test 是 100% Mare → **若不保留 Mare 高行训练样本, 模型只会 Rima 风格 Graben**。
Scene Split 暴露的性能下滑来自真实跨域难度，而非实现问题。

## R46 实验结果 (2026-07-20)

**配置**: dataset_v5 全量 Mare 训练 + R43 最佳模块 (Base模型, Tversky, 加权tile采样, 多尺度增强)
**Val 集**: 随机 5% 训练子集 (仅用于 epoch 选择)
**Test 集**: v5 独立 Mare 区域 (与 0.53 基准同一 test set)
**Best epoch**: 68

| 指标 | Val (5%子集) | Test (独立Mare区) |
|------|-------------|------------------|
| mIoU | 0.6433 | **0.4964** |
| Accuracy | 0.9829 | 0.9828 |

| 类别 | Val IoU | Test IoU | Test Recall | Test Prec | 分析 |
|------|---------|----------|-------------|-----------|------|
| Background | 0.983 | 0.983 | 98.9% | 99.3% | 正常 |
| Wrinkle Ridge | 0.565 | 0.448 | 69.9% | 55.5% | 28.9%漏判为背景 |
| Rille | 0.697 | 0.391 | 82.7% | 42.6% | 假阳性多 |
| Fault | 0.309 | 0.305 | 64.0% | 36.9% | 25.9%漏判为背景 |
| **Graben** | **0.662** | **0.354** | **46.5%** | 59.7% | **45.7%被判为背景** |

### 关键发现

- **val-test gap = 0.147**（0.643 → 0.496），gap 过大，说明 5% 随机 val 与 test 域差距严重
- **低于 v5 基准 0.53**：虽用了更强的模型和 loss，但 Rima 宽型 Graben（73% 训练像素）未能迁移到 Mare 细型 Graben
- Graben 核心问题：**45.7% 被预测为背景**，模型只学会了 Rima 风格，不认识 Mare 细条
- 结论：v5 全量训练数据不够，关键是 **Mare 风格 Graben 曝光量不足**

> 下一步：跑 R45 (v8 新切分, val=Mare低行, train含Mare高行Graben)，val 和 test 同属 Mare 域，gap 应大幅缩小

## R45 实验结果 (2026-07-21)

**配置**: dataset_v8 + Scene-Level Split (val=Mare低行WR区, train=Mare高行Graben区+其他)
**Val 集**: Mare Serenitatis 低行 (rows < 6447, WR丰富, **Graben极少**)
**Test 集**: v8 独立测试区
**Best epoch**: val_mIoU=0.650

| 指标 | Val | Test |
|------|-----|------|
| mIoU | 0.650 | **0.4128** |
| Accuracy | - | 0.9741 |

| 类别 | Test IoU | Test Recall | Test Prec | 分析 |
|------|----------|-------------|-----------|------|
| Background | 0.975 | 99.3% | 98.2% | 正常 |
| Wrinkle Ridge | 0.398 | 58.6% | 55.3% | 41%漏判为背景 |
| Rille | 0.417 | 83.0% | 45.5% | 假阳性多 |
| Fault | 0.169 | 37.2% | 23.6% | 严重漏检 |
| **Graben** | **0.106** | **11.4%** | 61.8% | **84.5%被判为背景，完全失效** |

### 关键发现

- **val-test gap = 0.237**（0.650 → 0.413），gap 极大
- **Graben 完全失效**：val 集（Mare低行）几乎不含 Graben，early stopping 选出的 best 模型对 Graben 无学习压力
- **比 R46 更差**（R46 test=0.496, Graben recall=46.5%）
- v8 Scene Split 的 val 设计对 Graben 有**结构性缺陷**：val 无 Graben → best checkpoint 不针对 Graben 优化
- 结论：**v8 路线不适合 Graben 检测**，v5 + R46 路线更优

### R45 vs R46 汇总对比

| 指标 | R46 (v5, 5%随机val) | R45 (v8, scene val) |
|------|---------------------|---------------------|
| Best val mIoU | 0.643 | 0.650 |
| Test mIoU | **0.4964** | 0.4128 |
| Test Graben IoU | **0.354** | 0.106 |
| Graben Recall | **46.5%** | 11.4% |
| Graben→背景 | 45.7% | **84.5%** |

> 下一步：在 R46 基础上提升 Graben，方向：增大 Graben weight (6.0+) / 形态腐蚀增强 / 改进 val 集
